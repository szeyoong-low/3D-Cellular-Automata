## Developer Environment Setup
Run `bash setup_dev_laptop.sh` from the `scripts` directory and follow any prompts it . This will auto-install all the dependencies. 

If you wish, run `bash confirm_environment.sh` from the same directory to verify that all of the dependencies were installed.

```
!! Note: dependency management is done through homebrew package manager, so homebrew and its dependencies will also be installed in the process.
```
